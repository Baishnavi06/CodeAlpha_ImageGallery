# Interactive Masonry Image Gallery

A fully responsive, Pinterest-style image gallery built as Task 1 for the CodeAlpha Frontend Development Internship.

## ✨ Key Features
* **Masonry Layout:** A dynamic grid that smoothly adapts to varying image heights.
* **Glassmorphism UI:** A modern, frosted-glass effect applied to the interactive lightbox overlay.
* **Dark/Light Mode:** A working theme toggle that remembers user preferences via local storage.
* **Dynamic Filtering:** Users can seamlessly sort the gallery by categories (Nature, Tech, Architecture).
* **Full Interactivity:** Includes keyboard-supported lightbox navigation and native image downloading.

## 🛠️ Tech Stack
* Semantic HTML5
* Modern CSS3 (CSS Variables, Multi-column Layouts, Backdrop Filters)
* Vanilla JavaScript (ES6+, DOM Manipulation, State Management)
